# 테스트와 실행 범위

저장소 루트에서 의존성을 준비한 뒤 다음 범위를 확인할 수 있다.

```powershell
python download_all.py --help
```

외부 원천 전체 수집이나 금융 성과 재현을 의미하지 않는다.

403/404, 요청 제한과 링크 변경이 발생할 수 있다. 공개 접근과 재배포 권리는 다르다. 대용량 수집에는 충분한 디스크가 필요하며 카탈로그의 175개 원천이 모두 자동 수집된다는 뜻은 아니다.

테스트 실행과 전체 원천 수집·학습은 별개다. 연구 결과는 [README](../README.md)의 당시 기록과 입력 조건을 함께 읽는다.
